# QQQ 시그마 경고 봇

QQQ(나스닥100)가 전일 대비 **2σ 이상 하락**하면 디스코드 채널에 경고를 보내는 봇입니다.
3σ로 더 벌어지면 단계마다 한 번씩 추가로 알립니다. 상승은 알리지 않아요.
경고에는 **과거 통계 한 줄**과 **±1σ/±2σ 밴드 차트**가 함께 붙어요.

- **σ(1시그마)**: 최근 252거래일(약 1년) 일간 수익률의 표준편차
- **Z**: 오늘 변동률 ÷ σ (예: -2.76σ = 평소 변동폭의 2.76배 하락)
- **누적 시그마**: N일 누적 변동률 ÷ (σ × √N). 하루하루는 작아도 며칠간 계속 빠지는 흐름을 잡아요.
  자동 알림은 3일 누적만 보내고, 5일 누적은 화면에 표시만 해요.
  하루 변동 알림이 이미 같은 단계 이상이면 중복을 막기 위해 누적 알림은 보내지 않아요.

## 1. 디스코드 봇 만들기
1. https://discord.com/developers/applications 에서 **New Application**을 만들어요.
2. **Bot** 탭에서 **Reset Token**을 눌러 토큰을 복사해요.
3. **OAuth2 → URL Generator**에서 `bot`과 `applications.commands`를 체크하고,
   Bot Permissions에서 `Send Messages`, `Embed Links`, `Attach Files`(차트 첨부용)를 체크해요.
4. 생성된 URL로 봇을 서버에 초대해요.
5. 디스코드 설정의 **고급**에서 **개발자 모드**를 켜요. 그다음 알림 채널을 우클릭해서 **ID 복사**를 해요.

## 2. 설치 및 실행
```bash
pip install -r requirements.txt
copy .env.example .env      # .env를 열어 DISCORD_TOKEN, CHANNEL_ID 입력
python bot.py
```

봇 없이 계산만 확인하려면 이렇게 실행해요:
```bash
python sigma.py QQQ ^NDX     # 현재 시그마, 누적 시그마
python stats.py QQQ          # 과거 통계 요약
python chart.py QQQ          # QQQ_chart.png 저장
```

## 3. 사용법
- 자동 경고: 5분마다 확인해요. 정규장은 감시 종목 전체, 나머지 세션은 `EXTENDED_TICKERS` 종목(기본 QQQ)만 봐요. 서머타임 기간에는 아래보다 1시간씩 빨라져요.
  | 세션 (한국 시간) | 현재가 | 기준가 |
  |---|---|---|
  | 프리장 18:00~23:30 | KIS | 직전 거래일 종가 |
  | 정규장 23:30~06:00 | KIS, 실패하면 Yahoo | 직전 거래일 종가 |
  | 애프터장 06:00~10:00 | KIS | 그날 정규장 종가 |
  | 주간거래 10:00~18:00 | KIS | 가장 최근 정규장 종가 |
  - 정규장 외 세션은 하루 변동 알림만 보내고, 세션별로 따로 기록해요. 세션이 시작되면 가격이 한 번 바뀐 뒤부터 봐요.
  - σ, 과거 통계, 차트는 Yahoo 일봉을 그대로 써요. KIS 키가 없으면 Yahoo로 정규장만 봐요.
- `/sigma`, `/sigma ticker:^NDX`: 현재 몇 시그마인지 바로 조회해요.
  - `/sigma days:63`: 이번 조회만 63거래일(약 3개월) 기준으로 계산해요. 설정은 바뀌지 않아요.
  - 결과 맨 아래에 **LOC 매수 참고가(-2σ)** = 전일 종가 × (1 − 2σ)가 나와요. 종가가 이 가격 이하로 끝나야 체결되고, σ는 전일까지 데이터로 계산하니 하루 동안 바뀌지 않아요.
  - `/sigma date:2026-10-30`: 지난 날짜 기준으로 계산해요. 현재가 대신 그날 종가가 나오고, -2σ LOC를 걸었다면 **체결됐을지(✅/❌)**도 알려줘요. 주말이나 휴장일을 넣으면 직전 거래일로 계산해요. `20261030`, `2026.10.30`, `10/30`(올해) 형식도 돼요. σ 기간 252일 기준으로는 2017년 11월 이후만 조회할 수 있어요.
- `/period`: 자동 알림에 쓰는 σ 기간을 보여줘요.
- `/period days:126`: 자동 알림 기준을 126거래일(약 6개월)로 바꿔요.
  - 바꾼 값은 `settings.json`에 저장돼서 재시작해도 유지되고, `.env` 값보다 우선해요.
  - 기본적으로 **서버 관리 권한**이 있는 사람만 쓸 수 있어요. 다른 사람에게 허용하려면
    서버 설정의 **연동 → 봇 → /period**에서 역할을 추가하면 돼요.
  - 입력 범위: 5~1000거래일 (21≈1개월, 63≈3개월, 126≈6개월, 252≈1년)
- `/stats`: 과거 약 9년 동안 하루 2σ 이상 하락한 날 이후 다음날, 5일 후, 20일 후 수익률을 보여줘요.
  평균, 중앙값, 상승 확률, 최고·최저, 최근 5번의 사례가 나와요.
  - `/stats level:1 direction:상승`: 1σ 이상 상승한 날 기준으로 봐요.
  - `/stats level:1 window:3`: 3일 누적 1σ 이상 하락한 뒤를 봐요. 연속된 날은 1번으로 세요.
- `/chart`, `/chart ticker:SPY days:126`: 종가와 ±1σ/±2σ 밴드 차트예요. 1σ 이상 움직인 날은 점으로 표시돼요.
- `/watch list`, `/watch add ticker:SOXX`, `/watch remove ticker:SPY`: 자동 알림 종목을 관리해요.
  - 추가할 때 실제로 시세가 나오는 티커인지 확인해요.
  - `settings.json`에 저장되고, `/period`처럼 기본은 서버 관리 권한자만 쓸 수 있어요.

## 4. 설정 (.env)
| 키 | 기본값 | 설명 |
|---|---|---|
| `TICKERS` | `QQQ` | 쉼표로 여러 개 입력 가능. 예: `QQQ,^NDX,TQQQ` (`/watch`로 바꾸면 그 값이 우선) |
| `LOOKBACK_DAYS` | `252` | σ 계산 기간(거래일). 252는 약 1년, 63은 약 3개월, 21은 약 1개월 |
| `CUMULATIVE_DAYS` | `3,5` | 화면에 보여줄 누적 시그마 기간 |
| `ALERT_CUMULATIVE_DAYS` | `3` | 그중 자동 알림까지 보낼 기간. 비우면 누적 알림을 꺼요 |
| `SIGMA_THRESHOLD` | `2` | 몇 σ 이상 하락부터 알릴지 |
| `CHECK_INTERVAL_MIN` | `5` | 확인 주기(분) |
| `ALERT_ROLE_ID` | (비움) | 알림 때 멘션할 역할 ID |
| `MARKET_HOURS_ONLY` | `true` | false로 두면 거래 시간이 아닐 때도 확인해요 |
| `KIS_APP_KEY`, `KIS_APP_SECRET` | (비움) | 한국투자증권 Open API 키. 시세 조회에만 써요. 주문 권한도 있는 키라 절대 공유하지 마세요 |
| `EXTENDED_TICKERS` | `QQQ` | 프리장·애프터장·주간거래까지 알릴 종목. 쉼표로 구분 |

## 주의
- Yahoo Finance 무료 데이터는 **약 15분 지연**될 수 있어요.
- 정규장 외 세션은 거래량이 적어 값이 크게 튈 수 있어요. 일간 σ는 정규장 종가 기준이라 의미가 조금 달라요.
- 증권사 시세는 재배포가 제한될 수 있어요. 다른 사람이 보는 채널로 알림을 보내기 전에 약관을 확인하세요.
- 과거 통계는 지나간 기록일 뿐이고 앞으로의 수익을 예측하거나 보장하지 않아요.
- 미국 공휴일은 따로 처리하지 않아요. 휴장일에는 시세가 변하지 않아서 알림이 오지 않아요.
- 알림 기록은 메모리에만 있어요. 같은 날 봇을 재시작하면 이미 보낸 알림이 한 번 더 올 수 있어요.
- PC를 끄면 봇도 멈춰요. 24시간 돌리려면 서버(VPS, Railway 등)에 올려야 해요.
